# ADR 0007: Profiles Cannot Weaken the Maker-Ready Baseline

Every Character Acceptance Profile inherits one non-optional Maker-Ready Baseline covering the authoritative Cut Line, protected print geometry, clean Trace Pages, accepted-layer export fidelity, and absence of transient or source artwork in exports. Fixture profiles may add stricter source-specific expectations but cannot disable baseline checks, preventing a difficult character from passing by weakening universal product guarantees at the cost of requiring genuine pipeline fixes or explicit human waivers outside automated success.
