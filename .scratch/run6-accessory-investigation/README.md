# Compound defining accessory investigation fixture

This fixture is original, deterministic geometry created for the Run 6
investigation. It contains a simple light subject and a neutral elongated
accessory with a larger body, narrow connector, crossing thin component,
enclosed detail, an intentional small gap, dark-background exposure, and a
distant artifact that should remain excluded.

The low and high resolution PNGs are proportional renders of the same source.
The fixture is intentionally neutral and must not be identified with a named
character or real-world instrument in production logic.

Regenerate both sources with:

```text
python generate_fixture.py
```
